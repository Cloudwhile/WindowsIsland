# 安装、便携与卸载

## 安装版

1. 从[下载页](./index.md)获取 `.exe` 安装器，按需要校验 SHA-256。
2. 运行安装器，选择安装目录。
3. 出现管理员授权请求时，按提示完成授权。
4. 安装完成后，从开始菜单打开消息岛。
5. 参照[快速开始](../guide/getting-started.md)选择来源，并按需完成系统通知初始化和授权。

升级时选择原安装目录。安装器会关闭该目录正在运行的消息岛并替换文件。

## ZIP 便携版

1. 下载 ZIP 及其同名校验文件。
2. 完整解压到准备长期使用的目录。
3. 从解压目录运行 `WindowsIsland.exe`。
4. 如果需要系统通知，在应用内完成初始化与通知访问授权。

保留目录中的配套文件，不要只复制 EXE。便携版不创建开始菜单和卸载入口，也不提供开机自启入口；系统通知初始化仍可能请求一次管理员授权。

## 移动便携目录

启用过系统通知后，不要直接移动已登记的目录：

1. 在 **初始化** 页选择 **注销稀疏包注册**。
2. 确认并等待消息岛退出。
3. 移动完整目录，在新位置打开应用。
4. 需要系统通知时，在新目录重新初始化。

## 卸载安装版

从 Windows **设置 → 应用 → 已安装的应用**（Windows 10 中为 **应用和功能**）找到消息岛并卸载。

卸载会清理对应安装目录的应用登记和自启项，用户数据保留。此前自行导出的诊断报告不会被删除。

## 删除便携版

在 **初始化** 页选择 **注销稀疏包注册**，确认后等待消息岛退出，再删除便携目录。未使用系统通知时，也应先退出应用再删除文件。

## 遇到权限问题

取消初始化或安装授权后，可稍后重试。先查看应用提示，并在[诊断与反馈](../guide/troubleshooting.md#生成诊断报告)中导出问题信息。
