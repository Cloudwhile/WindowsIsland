# 更新与预发布

## 应用内更新

1. 打开 **更新** 页，点击检查图标。
2. 查看可用版本、发布说明与下载大小。
3. 点击下载图标准备安装器，等待下载和校验完成。
4. 按页面提示启动安装；安装版可能申请 Windows 管理员授权。
5. 应用重新打开后，在更新页查看结果与当前运行版本。

更新保留已有偏好，并在重新打开后恢复正常消息监听。需要系统通知时，应用会刷新相关初始化登记。

## 取消、中断与重试

下载时可查看百分比和传输速率。网络中断或取消后可重试，已下载的有效片段可以继续使用。

校验失败时不会继续安装。取消管理员授权后原应用保留，可重新准备或启动更新。

如果重启后仍显示旧版本，不要只根据安装器曾打开判断成功；查看更新页结果，或使用同版本安装器手动覆盖安装。

## 接收预发布更新

**接收预发布更新** 默认关闭。需要体验预发布版本时，在更新页打开开关，再重新检查。

关闭开关后只查找符合条件的正式版，不会自动把当前预发布版本降级。改变渠道后，需要重新检查才能安装新的候选版本。

## 手动升级

如果旧版本的更新功能不可用：

1. 从[下载页](./index.md)打开对应的 Release。
2. 阅读该版本升级说明并下载 x64 安装器。
3. 校验文件后运行安装器，选择当前应用所在目录。
4. 按提示完成安装，重新打开并核对版本。

便携目录使用应用内更新时会保持便携方式。手动更新便携版时，优先采用该版本说明给出的方式；如果改用 ZIP，先退出消息岛，备份原目录，再完整解压，避免混用不同版本的文件。
