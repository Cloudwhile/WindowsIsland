# 消息来源

在 **消息来源** 页为每个来源单独启停、查看状态或重试。点击来源名称或尾部箭头，可展开版本、作者、插件标识和文件信息。

## 系统通知

系统通知来源接收 Windows 新通知，包括 QQ 等应用通过系统发出的提醒。

1. 在 **初始化** 页完成应用初始化。
2. 允许消息岛访问通知。
3. 在 **消息来源** 页开启系统通知。
4. 让目标应用产生一条新的通知。

初始化后可能会自动重启消息岛。若授权弹窗没有出现，可从初始化页打开 Windows 通知设置，再返回刷新状态。

应用自己没有发送 Windows 通知时，这个来源也无法产生消息。检查目标应用自己的通知开关，避免用历史通知判断连接是否正常。

## 微信

微信来源从已登录的桌面客户端接收新消息和未读预览，并在可用时显示会话头像。

1. 运行并登录桌面微信。
2. 如果消息岛提示辅助访问相关问题，按提示在微信设置中开启辅助访问。
3. 返回 **消息来源** 页开启微信，必要时点击重试图标。
4. 收到新的非免打扰会话消息后查看结果。

微信来源尊重会话免打扰，启动或重新连接不会重放历史消息。客户端版本或窗口可访问性发生变化时，连接可能失败，可重试或使用系统通知来源接收提醒。

系统通知需要独立完成初始化与授权。只有该来源可用且微信发出系统通知时，系统通知才能作为替代途径。

## Telegram

1. 运行并登录 Telegram 桌面版。
2. 在 **消息来源** 页开启 Telegram。
3. 客户端启动较晚时刷新状态，必要时重新开启来源。

Telegram 来源接收连接后的新消息，不重放历史内容。显示未运行时先检查桌面客户端，连接失败时参见[排障步骤](./troubleshooting.md)。

## 电源

电源来源在接入电源、开始充电、断开电源或充满电时显示提醒。没有相应电源变化时，不会持续发送通知。

## 连接状态

| 状态 | 含义与下一步 |
| --- | --- |
| 已连接 / 已开启 | 来源可用，等待新消息或事件 |
| 已关闭 | 来源已停用，可打开开关 |
| 未运行 | 对应桌面客户端尚未运行或未被检测到 |
| 未连接 | 检查客户端登录、初始化或授权 |
| 连接失败 | 查看第二行说明，修复后点击重试 |

关闭一个来源不会关闭其他来源。切换设置页面也不会停止消息监听。

## 外部来源

安装的外部插件同样出现在 **消息来源** 页，使用相同的启停、状态和详情入口。安装方式见[安装与管理插件](./plugins.md)。
