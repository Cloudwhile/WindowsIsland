# 安装与管理插件

**插件列表** 页用于导入和获取插件；**消息来源** 页用于管理安装后的来源、状态与设置。

## 手动导入

1. 从可信开发者获取插件 ZIP 包。
2. 打开 **插件列表** 页，点击手动导入图标。
3. 选择 ZIP，核对名称、版本、作者和权限说明。
4. 按界面提示完成安装。
5. 在 **消息来源** 页找到插件，开启并查看结果。

插件 ZIP 与消息岛应用的便携 ZIP 是两种不同的文件，不能互相导入。开发者提供的包应直接包含插件清单，无需手动解压到应用目录。

进程内插件使用应用本身的系统权限，请仅安装可信来源的插件。手动插件的部分宿主能力受限，可能与开发者演示的官方目录版本有所不同。

## 官方源

[开放平台](https://wini-plugins.abszero.cc/)目前尚未开放，应用默认使用该地址。现在请使用手动 ZIP 导入插件。

可在插件列表页编辑目录基地址并点击保存图标，下次刷新生效。地址无效时目录停用，修正后可重新刷新。

目录服务开放后，可在插件列表页刷新并按开发者浏览已收录插件。安装或更新前，先检查版本、权限与最低消息岛版本要求。

官方源无法访问时，可使用开发者提供的手动 ZIP；不要把任意地址或仓库当作已经审核的官方目录。

| 行内说明 | 处理方式 |
| --- | --- |
| 已是最新版 | 无需更新 |
| 其他安装来源 | 使用原安装来源更新，先核对插件身份 |
| 开发者不同 | 核对作者与插件来源 |
| 合约不兼容 | 选择与当前消息岛兼容的插件版本 |
| 宿主版本过低 | 先更新消息岛 |
| 已下架 | 已安装项仍保留，可自行决定继续使用或删除 |

## GitHub 代理

插件列表页提供可选的 **GitHub 代理**。填写代理服务的 HTTPS 前缀地址并点击保存图标；留空并保存则直连 GitHub。该设置只影响官方插件的 GitHub 下载，目录基地址另行配置，下载后仍校验文件完整性。

例如，代理服务要求把原始 GitHub 地址接在 `https://proxy.example/` 后时，填写该前缀即可。请使用你信任的代理服务。

## 插件设置

在 **消息来源** 页点击插件名称或右箭头进入详情，使用左上角返回图标回到列表。插件可以提供文本和开关设置；即使停用，仍可编辑这些设置。

详情同时显示版本、类型、作者、标识、程序集位置和大小。内置来源共享主程序集，显示的文件大小并非独立插件安装包大小。

## 更新与覆盖

默认只提供稳定版插件，更新页的预发布选项也适用于目录插件。目录冻结版本仍可新装；下架只显示警告，已安装插件继续运行。

导入相同版本时，按提示决定是否覆盖；低于已安装版本的包不能直接安装。官方目录的更新也需要核对来源与开发者，并可能要求重新确认权限。

## 停用与删除

- **停用**：关闭来源开关，停止该插件，后续可以再次开启。
- **删除**：使用外部插件行的删除图标，停止插件并移除代码和来源项；插件设置及数据目录保留，同标识重装可继续读取。

内置来源可以停用，不能从列表删除。

要编写自己的插件，继续阅读[插件开发](../plugins.md)。
