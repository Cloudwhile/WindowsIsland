# 安装与管理插件

即使是默认插件源，我们也不能完全保证插件的稳定性和安全性，使用前请谨慎核查。

**插件管理** 页分为 **已安装** 和 **发现插件**，用于安装、查看详情与卸载；**消息来源** 页用于管理各来源的启停、连接状态与设置。

## 手动导入

1. 从可信开发者获取插件 ZIP 包。
2. 打开 **插件管理** 页，点击右侧安装图标。
3. 选择 ZIP，核对名称、版本、作者和权限说明。
4. 按界面提示完成安装。
5. 在 **消息来源** 页找到插件，开启并查看结果。

插件 ZIP 与消息岛应用的便携 ZIP 是两种不同的文件，不能互相导入。开发者提供的包应直接包含插件清单，无需手动解压到应用目录。

插件安装后默认关闭。启用前请核对身份和版本；有使用条款时先阅读并同意，需要联网时还会说明目的地、用途和数据类别。更新或覆盖安装后需要重新确认，取消后保持关闭。

插件只能使用自身数据，不能读取消息岛本体或其他插件的数据。启用时阅读并确认开发者或默认插件源提供的联网须知，之后插件可在声明范围内后台联网，不再逐次弹窗。

## 默认插件源

开放平台已开放，可在 **插件管理 → 发现插件** 查看已收录的插件。

点击刷新并按开发者浏览插件。安装或更新前，先检查版本、权限与最低消息岛版本要求。目录为空表示当前没有可展示的已收录插件。

默认插件源无法访问时，支持手动安装的插件可使用开发者提供的 ZIP；不要把任意地址或仓库当作已经审核的默认插件源。微信连接能力需要默认源验证，手动导入微信 ZIP 不能作为替代。

| 行内说明 | 处理方式 |
| --- | --- |
| 已是最新版 | 无需更新 |
| 其他安装来源 | 使用原安装来源更新，先核对插件身份 |
| 开发者不同 | 核对作者与插件来源 |
| 合约不兼容 | 选择与当前消息岛兼容的插件版本 |
| 宿主版本过低 | 先更新消息岛 |
| 已下架 | 已安装项仍保留，可自行决定继续使用或删除 |

## GitHub 代理

在 **插件管理 → 发现插件** 展开 **高级设置**，可配置 **GitHub 代理**。填写代理服务的 HTTPS 前缀地址并点击保存图标；留空并保存则直连 GitHub。该设置只影响默认源插件的 GitHub 下载，下载后仍校验文件完整性。

例如，代理服务要求把原始 GitHub 地址接在 `https://proxy.example/` 后时，填写该前缀即可。请使用你信任的代理服务。

## 插件设置

在 **消息来源** 页点击插件名称或右箭头进入详情，使用左上角返回图标回到列表。插件可以提供文本和开关设置；外部插件首次提供动态设置前，请先完成启用确认并开启插件。

系统通知和电源提醒随应用提供，在 **消息来源** 页分别开关并查看详情。微信和 Telegram 为独立官方插件，作者为 `winiofficial`；收录状态以 **插件管理 → 发现插件** 列表为准，从该列表安装后也会出现在消息来源页。

在 **插件管理 → 已安装** 也可进入详情。详情按基本信息、权限与能力、安装信息分组，显示版本、类型、作者、标识、程序集位置和大小；标识和路径可选择或点击复制图标。内置来源共享主程序集，显示的文件大小并非独立插件安装包大小。

## 更新与覆盖

默认只提供稳定版插件，更新页的预发布选项也适用于目录插件。目录冻结版本仍可新装；下架只显示警告，已安装插件继续运行。

导入相同版本时，按提示决定是否覆盖；低于已安装版本的包不能直接安装。安装与更新后插件保持关闭，下次启用时重新核对条款和联网说明；官方作者也需要经过相同确认。

## 停用与删除

- **停用**：关闭来源开关，停止该插件，后续可以再次开启。
- **卸载**：在 **插件管理 → 已安装** 中进入外部插件详情，点击删除图标并确认。卸载停止插件并移除代码和来源项；插件设置及数据目录保留，同标识重装可继续读取。

内置来源可以停用，不能从列表删除。

要编写自己的插件，继续阅读[插件开发](../plugins.md)。
