# 外观与偏好

设置自动保存。点击托盘图标即可重新打开；关闭设置后，消息岛继续在后台运行。

## 设置导航

| 页面 | 内容 |
| --- | --- |
| 初始化 | 应用初始化、通知访问、安装版的开机自启 |
| 消息来源 | 来源开关、连接状态、插件详情、静音与系统免打扰 |
| 插件列表 | 手动导入插件与官方源 |
| 外观 | 位置、动画、毛玻璃、透明度和语言 |
| 更新 | 检查、下载、安装更新与预发布开关 |
| 诊断与反馈 | 本机记录、报告与反馈入口 |

预览图标位于 **消息来源** 和 **外观** 页。刷新图标位于 **初始化**、**消息来源** 和 **插件列表** 页。

## 位置

可选择左上、左中、左下、中下、右下、右中、右上、中上。选择后使用预览确认显示位置。

固定详情在顶部位置向下展开，在底部位置向上展开，长内容可在详情中滚动。

## 动画

开启时，消息岛从所选屏幕边缘展开并收起；关闭时，状态立即切换。透明度过渡另有独立开关。

## 毛玻璃与透明度

| 选项 | 效果 |
| --- | --- |
| 毛玻璃 | 调整通知背景的模糊效果 |
| 背景透明度 | 在 0–80% 范围调整背景通透程度 |
| 透明度过渡 | 控制显隐时的透明度变化 |

背景透明度不降低正文与头像的清晰度。Windows 关闭透明效果或开启高对比度时，背景使用系统主题的可读性回退。

## 语言

在外观页选择 **简体中文**、**English** 或 **跟随系统**。选择后即时更新设置、状态和托盘菜单，下次启动沿用已保存的选择；消息原文不翻译。

## 开机自启

安装版可在 **初始化 → 通用** 中开启开机自启。默认关闭，操作时可能出现 Windows 管理员授权请求；取消后可稍后重试。

开启后，登录 Windows 时在后台启动，不主动打开设置。便携版不提供开机自启入口。

## 诊断采集

在 **诊断与反馈** 页可关闭本机诊断采集。关闭后仍可查看、复制、导出或清除已保存的记录，不影响消息接收。具体步骤见[常见问题与反馈](./troubleshooting.md#生成诊断报告)。
