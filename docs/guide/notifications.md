# 通知与固定内容

## 普通通知

消息显示应用图标、可用的会话头像、标题和正文。长正文会换行，超出显示范围时省略。

每条消息显示约五秒，新消息替换当前内容后重新计时。同一消息从多个来源到达时会尽量合并；后补头像等信息不会延长显示时间。

| 操作 | 结果 |
| --- | --- |
| 左键消息 | 打开对应程序，如果该来源提供了可用的目标 |
| 右键消息 | 关闭当前消息，继续接收后续消息 |
| 等待自动收起 | 当前消息结束，恢复固定内容或屏幕边缘的最小状态 |

## 固定内容

支持固定内容的插件可以持续显示一个简短值，例如状态或计数。固定内容由插件主动更新和撤下，不受普通消息的五秒时限影响。

全局同时显示一项固定内容，最近提交的一项会替换之前的一项。

- 只有简短值时，消息岛保持紧凑显示。
- 有说明、控件或可用详情时，可点击展开。
- 在详情中操作插件提供的按钮、开关或滑块。
- 按 Esc、点击岛体外部或点击关闭图标，返回紧凑显示。

普通消息优先显示。消息打断固定详情后，消息结束会回到紧凑态，不会自动重新打开详情。停用或删除所属插件也会撤下固定内容。

## 游戏与全屏静音

在 **通知行为** 页分别设置游戏和全屏静音，两项默认开启。

满足已开启的静音条件时，消息岛隐藏弹窗，期间的消息不在结束后补弹。固定内容保留，退出静音后恢复紧凑显示。

如果能看到预览，却收不到真实消息，先检查来源是否连接，再查看是否满足静音条件。

## Windows 系统免打扰

**通知行为 → 通知显示** 中的系统免打扰开关控制 Windows 自身的免打扰状态，和消息岛的游戏、全屏静音分别设置。

开启系统免打扰可以减少 Windows 横幅打扰，消息岛继续接收消息。Windows 的优先通知例外和自动规则仍按系统设置生效。

系统接口不可用时，可使用同一行的 Windows 设置入口调整。具体显示结果取决于 Windows 版本、规则和目标应用的通知行为。
