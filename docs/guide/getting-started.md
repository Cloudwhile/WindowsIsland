# 快速开始

消息岛在屏幕边缘显示桌面消息。先安装并打开应用，再按需要启用系统通知、微信、Telegram 或电源来源。

## 1. 下载并打开

前往[下载消息岛](../download/index.md)，选择 Windows 安装器或 ZIP 便携包。支持 Windows 10 2004 及以上版本、Windows 11，适用于 x64 设备。

- **安装版**：运行 `.exe` 安装器，选择目录，按提示完成安装，从开始菜单打开消息岛。
- **便携版**：完整解压 ZIP，在解压目录打开 `WindowsIsland.exe`。

不要直接在压缩包中运行程序。详细步骤见[安装、便携与卸载](../download/install.md)。

## 2. 按需启用系统通知

如果需要接收 QQ 等应用的 Windows 通知：

1. 打开设置，在 **概览** 页通过配置提示进入初始化；需要时先在 **消息来源** 页开启 **系统通知**。
2. 按顺序完成 **应用初始化**；出现 Windows 管理员授权时，按提示决定是否允许。
3. 在 **通知访问** 一行点击授权图标，允许消息岛访问通知。
4. 检查通知状态，点击完成图标返回概览。

“系统通知尚未就绪”只表示系统通知的初始化或访问授权尚未完成。已连接的微信等独立来源和通知预览仍然可用。

## 3. 选择消息来源

在 **消息来源** 页打开需要的来源。微信和 Telegram 需要先运行并登录对应的桌面客户端。

| 来源 | 接收内容 | 准备工作 |
| --- | --- | --- |
| 系统通知 | Windows 新通知 | 完成初始化并允许通知访问 |
| 微信 | 新消息、未读预览和可用的会话头像 | 登录桌面微信，按需要开启客户端辅助访问 |
| Telegram | 桌面客户端的新消息 | 登录 Telegram 桌面版 |
| 电源 | 接入、断开、充电及充满提示 | 开启来源即可 |

通过页头预览图标查看显示效果。各来源的连接方法见[消息来源](./sources.md)。

## 4. 调整外观

进入 **外观** 页，选择位置、动画、毛玻璃与透明度。显示器示意会随设置变化，点击真实通知预览图标确认桌面效果。可选八个位置：左上、左中、左下、中下、右下、右中、右上、中上。

语言可选简体中文、English 或跟随系统，设置会自动保存。更多选项见[外观与偏好](./settings.md)。

## 5. 留在后台接收消息

关闭设置窗口后，消息岛继续在系统托盘运行。

- 点击托盘图标重新打开设置。
- 右键托盘图标查看状态或退出应用。
- 普通消息约五秒后收起；新消息会重新计时。
- 左键消息打开对应程序（如果可用），右键关闭当前消息。

通知置顶显示，出现时保留当前应用的输入焦点。固定内容和消息的区别见[通知与固定内容](./notifications.md)。
